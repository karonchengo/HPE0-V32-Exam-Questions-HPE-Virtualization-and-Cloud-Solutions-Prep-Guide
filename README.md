- Describe cloud and virtualization concepts.
- Compare common container use cases and their benefits.

Preparation should focus on understanding how cloud delivery models, virtualization, and container technologies support modern IT environments. You should also understand how HPE GreenLake provides a flexible approach to consuming infrastructure and cloud services.

This domain focuses on the architecture and implementation of HPE Private Cloud Business Edition.

- Deployment architecture and solution components.
- Single Click Update capabilities.
- Active Peer Persistence support.

You should understand how the different components work together to provide a private cloud environment and how management and update capabilities support ongoing operations.

Pay particular attention to the architecture and deployment process, as these concepts help explain how HPE Private Cloud Business Edition is implemented and managed.

### 3. Explain the HPE Private Cloud Enterprise Solution — 15%

This domain examines HPE Private Cloud Enterprise and its role in delivering enterprise private cloud capabilities.

Candidates should understand:
- The managed service framework.
- Supported workloads and solution building blocks.
- Service delivery and support capabilities.
- Competitive positioning and alternative solutions.

Preparation should focus on how HPE Private Cloud Enterprise supports enterprise workload requirements, how its managed service framework operates, and how its architecture differs from other private cloud offerings.

### 4. Summarize HPE Private Cloud AI Capabilities and Use Cases — 12%

HPE Private Cloud AI is an important part of the updated HPE infrastructure portfolio. This domain evaluates your understanding of its capabilities, architecture, and potential applications.

Candidates should be able to:
- Explain the core capabilities of HPE Private Cloud AI.
- Identify appropriate use cases for the solution.
- Describe the components used to build an HPE Private Cloud AI solution.
- Evaluate alternative approaches to delivering private AI infrastructure.

Focus on understanding how an integrated private AI environment supports enterprise AI workloads and how its components contribute to an overall solution.

You should also understand why organizations may choose a private AI infrastructure approach instead of other available AI deployment models.

### 5. Summarize the Positioning of HPE Morpheus VM Essentials Software — 12%

This domain focuses on the positioning and architecture of HPE Morpheus VM Essentials Software.

Preparation should focus on understanding how HPE Morpheus VM Essentials Software supports virtualized environments and how it fits into HPE's broader virtualization and cloud portfolio.

### 6. Summarize HPE Morpheus Enterprise Software Core Capabilities and Architecture — 12%

HPE Morpheus Enterprise Software is a major topic in this exam. This domain covers its architecture, installation, configuration, administration, provisioning, and monitoring capabilities.

- HPE Morpheus Enterprise Software architecture and core capabilities.
- Installation and configuration processes.

- Roles, permissions, users, and user settings.
- Provisioning concepts and provisioning steps.

A good understanding of the relationship between groups, clouds, roles, and permissions is particularly important. Candidates should also understand how provisioning workflows and service catalogs help organizations automate infrastructure delivery.

This domain evaluates your knowledge of data protection technologies and the role of HPE Zerto Software in enterprise resilience.

- Local replication technologies, including snapshots and recovery methods, and how they differ from traditional backups.
- Data classification, backup requirements, protection methods, and restore procedures.
- HPE Storage Tape solutions and their role in tape-based data protection.

Candidates should understand the differences between replication, snapshots, and backups. These technologies serve different purposes and provide different approaches to protecting and recovering business-critical data.

Another important area is understanding how recovery architectures support different customer requirements, including rapid recovery, isolation, and immutable data protection.

### 8. Explain HPE OpsRamp Software and Its Key Solution Capabilities — 12%

The final domain focuses on HPE OpsRamp Software and its role in enterprise IT operations management and monitoring.
